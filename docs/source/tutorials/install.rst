Installation & Build
====================

RV_TESTER builds with `Bazel <https://bazel.build/>`_ (bzlmod).

Build and test
--------------

.. code-block:: sh

   # Build the exported targets
   bazel build //...

   # Run the tests
   bazel test //test/...

Nested ``README`` files under ``src/`` (e.g. ``src/cosim/``, ``src/sysmod/``) document
individual subsystems in more detail; those are summarized in the :doc:`/user_guides/index`.

Running the SW testbench
------------------------

The software testbench validates rv_tester without a full-chip simulation. From
``test/sw_testbench``:

.. code-block:: sh

   mkdir testing
   cd testing
   ../../infra/bzsim test smoke

The extra ``testing`` directory prevents the ``BUILD.bazel`` file generated by ``bzsim`` from
overwriting the existing ``BUILD.bazel`` files in the repo. See :doc:`/user_guides/sw_testbench`
for details.
